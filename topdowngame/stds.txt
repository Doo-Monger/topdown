Tentative knowledge of "as" keyword:
	It performs "runtime casting", the static version of casting is ":", which we are already
	familiar with. "as" is useful when you don't know the exact type of object whenever the
	method it is a part of is declared
	
	For example...
	coins_in_my_pocket = $Quarter as Coin, where Coin is assumed to be a superclass of $Quarter,
	and $Quarter by extension is a derived class (or subclass) of Coin.
	In this example, the as operator is used to ensure that coins_in_my_pocket will always be
	typed as a Coin, rather than any of its existing subclasses, say for example $nickel
	or $penny (young sheldon). If the value is not of the target type, or a subtype of the 
	target type - say, for example "$dollar", then it would return null.
